Enumerate all interactive or visually distinct elements visible in this image.

What counts as an "element" depends on the image type. For a UI: buttons, inputs, toggles, icons, labels. For a photo: objects, people, signs, landmarks. For a chart: bars, axes, legend entries, data points. Use your judgment — list everything that matters.

For each element, return:
- label: what it is
- type: what kind (button, icon, person, tree, bar, axis, etc.)
- bbox: [x1, y1, x2, y2] in pixels, with (0,0) at top-left

Output as a compact JSON array. No markdown, no explanation.
